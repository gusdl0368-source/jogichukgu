# 새벽 조기축구 베타 0.9.0 점검표

베타 범위는 **게임 루프 전체가 동작하고, 저장이 안전하고, 처음부터 엔딩까지 막힘 없이 갈 수 있는 상태**입니다.
실제 결제, 광고, 앱 스토어 등록은 베타 범위 밖입니다(아래 "정식 출시 전 남은 일" 참고).

## 1. 기능 (베타에서 완료)

| 영역 | 상태 | 확인 방법 |
|---|---|---|
| 스카우트 → 비교 → 영입/방출 | ✅ | 단위 테스트, 브라우저 |
| 9단계 세계 무대 리그와 승격, 엔딩 | ✅ | 단위 테스트(승격, 엔딩), 시뮬레이터 |
| 15개국 선수·국기·국가별 이름 | ✅ | 단위 테스트(등급별 국적 비율) |
| 선수 특성 10종 → 경기 보정 | ✅ | 단위 테스트 |
| 경기 이벤트: 반칙, 프리킥, 페널티킥, 옐로/레드카드 | ✅ | 단위 테스트, 경기당 평균 수치 확인 |
| 경기 운영(닥공/균형/버스) | ✅ | 단위 테스트(득실 변화) |
| 일일 미션 5종 + 완료 상자 | ✅ | 단위 테스트, 브라우저 |
| 가이드 퀘스트 23단계 (온보딩 겸용) | ✅ | 단위 테스트, 브라우저 |
| 훈련 캠프 3종 + 소탕, 리그별 난이도 상한 | ✅ | 단위 테스트, 브라우저 |
| 전술 연구(시간제), 팀 스킬 소환·레벨업 | ✅ | 단위 테스트, 브라우저 |
| 동네 대항전(일일 시즌, 순위 보상) | ✅ | 단위 테스트, 브라우저 |
| 상점: 광고 보상, 슈퍼스타 제안, 구독, 패스, 특가, 젬, 스폰서 | ✅ (가짜 결제) | 단위 테스트, 브라우저 |
| 오프라인 진행(운동장 수익, 경기 최대 6판) | ✅ | 단위 테스트 |
| 연출: 카드 공개, 대박 연출, 축포, 관중, 효과음 | ✅ | 브라우저 스크린샷 |

## 2. 저장 안전성

| 항목 | 상태 |
|---|---|
| 브라우저 저장 (막힌 환경에서도 게임은 동작) | ✅ |
| claude.ai 계정 저장 (보는 사람 전용, 30초에 한 번까지, 바뀐 것이 있을 때만) | ✅ 코드 / ⚠️ 실제 계정 환경 확인 필요 |
| 저장 코드 내보내기/가져오기 | ✅ |
| v1(알파) 저장 → v2 자동 이전, 진행 유지 | ✅ 단위 테스트 |
| 깨진/모르는 버전 저장은 무시하고 새 게임 | ✅ 단위 테스트 |

## 3. 밸런스 (시뮬레이터 `npm run sim`)

| 플레이 습관 | 엔딩까지 |
|---|---|
| 하루 4번 × 15분, 무과금 | 21~34일 (시드 4개) |
| 하루 2번 × 10분, 무과금 | 32~33일 (시드 2개) |

- 첫날: 2~3번 승격(지역 → 3부/2부), 이후 1~4일마다 한 단계.
- 병목은 연락처(스카우트 횟수). 회비는 후반에 남는 편이라, 정식 출시 전 회비 사용처(예: 선수 훈련) 추가를 검토.
- 마지막 리그는 운에만 기대지 않도록 상대 등급을 한 단계 섞어서 조정함.

## 4. 브라우저 확인 (휴대폰 390×844, Chromium)

- 튜토리얼 → 스카우트 → 영입 → 확률표 → 자동 스카우트 → 각 탭 → 승부차기 미니게임 → 연구 → 소환 → 대항전 → 구매 확인 → 경기 종료 → 시즌 종료 → 설정·패치 노트 → 초기화
- 콘솔 오류 0건 (효과음은 첫 터치 이후에만 재생)

## 5. 정식 출시 전 남은 일

| 항목 | 메모 |
|---|---|
| 실제 결제 연동 | 앱 스토어/구글 플레이 결제, 영수증 서버 검증 |
| 광고 SDK | "벤치 휴식", 캠프·대항전 추가 입장, 운동장 보너스 자리 마련됨 |
| 확률형 상품 표시 | 스카우트 확률표는 공개됨. 스킬 소환 확률도 화면에 있음. 유료 재화로 직접 뽑는 상품은 없음 |
| 앱 포장 | 웹 빌드를 Capacitor 등으로 감싸기, 아이콘·스플래시 |
| 서버 저장/치트 방지 | 지금은 기기 저장이 기준. 랭킹 경쟁을 넣으려면 서버 판정 필요 |
| 진짜 PvP 대항전 | 지금은 다른 구단을 흉내 낸 봇 |
| 아트·사운드 | 픽셀 얼굴은 자동 생성, 효과음은 합성음. 전문 아트·BGM으로 교체 권장 |
| 다국어 | 현재 한국어만 |
| 개인정보처리방침, 연령 등급 | 스토어 등록 시 필요 |
| 지표 수집 | D1/D7 리텐션, 첫 세션 길이, 가이드 단계별 이탈 |
| 베타 테스터 피드백 | 손맛, 첫 15분 흐름, 막판 속도 |
