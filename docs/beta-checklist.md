# 새벽 조기축구 베타 0.19.2 점검표

베타 범위는 **게임 루프 전체가 동작하고, 저장이 안전하고, 처음부터 엔딩까지 막힘 없이 갈 수 있는 상태**입니다.
실제 결제, 광고, 앱 스토어 등록은 베타 범위 밖입니다(아래 "정식 출시 전 남은 일" 참고).
처음 점검은 0.9.0에서 했고, 이 문서는 0.19.2 기준으로 다시 정리했습니다.

## 2. 저장 안전성

| 항목 | 상태 |
|---|---|
| 브라우저 저장 (막힌 환경에서도 게임은 동작) | ✅ |
| IndexedDB 백업: localStorage가 지워지면 다음 접속 때 되살림 (0.19.2) | ✅ 브라우저 확인 |
| claude.ai 계정 저장 (보는 사람 전용, 30초에 한 번까지, 바뀐 것이 있을 때만) | ✅ 코드 / ⚠️ 실제 계정 환경 확인 필요 |
| 저장 코드 내보내기/가져오기 | ✅ |

| 게임 모음 사이트(saaskr) 안에서 저장 | ✅ 브라우저 확인. 여러 게임이 한 주소를 같이 쓰므로 위 백업이 중요 |

## 3. 밸런스 (시뮬레이터 `npm run sim`)

하루 4번 × 15분 접속, 경기 한 판 90초, 시드 4개(1~4) 기준 엔딩까지 걸린 날:

| 플레이 습관 | 명령 | 엔딩까지 | 가운데 값 |
|---|---|---|---|
| 무과금, 광고 안 봄 | `SIM_NO_ADS=1 npm run sim -- 120` | 71~107일 | 약 78일 |
| 무과금, 광고 봄 | `npm run sim -- 120` | 49~66일 | 약 63일 |
| 광고 + 시즌 패스 + 정회원 | `SIM_PASS=1 SIM_MEMBER=1 npm run sim -- 120` | 19~46일 | 약 39일 |

- 후반 병목은 연락처(스카우트 횟수). 회비는 후반에 크게 남는다.
- 시드에 따라 차이가 커서(특히 광고 안 봄), 숫자는 대략적인 범위로 본다.

## 4. 브라우저 확인 (Chromium)

| 화면 크기 | 확인한 것 |
|---|---|
| 390×844 (일반 폰) | 튜토리얼 → 스카우트 → 각 탭 → 경기 종료 → 팝업 열고 닫기, 콘솔 오류 0건 |
| 375×667, 360×640 (작은 폰) | 압축 레이아웃에서 빠른 메뉴가 가려지지 않고 선수 카드가 첫 화면에 보임 |
| 800×450 (PC에서 사이트 안에 끼워진 창) | 타이틀 글씨 겹침 없음, 경기장 전체가 보임 |
| 358×202 (폰에서 사이트 안에 끼워진 창) | 전체 화면 안내 → "이대로 하기"로 진행 가능 |
| 팝업 깜빡임 | 팝업을 띄운 채 경기가 끝나도 창을 다시 만들지 않음 (0.19.2) |

## 5. 정식 출시 전 남은 일

| 항목 | 메모 |
|---|---|
| 실제 결제 연동 | 앱 스토어/구글 플레이 결제, 영수증 서버 검증 |
| 광고 SDK | "벤치 휴식", 캠프·대항전 추가 입장, 운동장 보너스 자리 마련됨 |
| 확률형 상품 표시 | 스카우트 확률표는 공개됨. 스킬 소환 확률도 화면에 있음. 유료 재화로 직접 뽑는 상품은 없음 |
| 앱 포장 | 웹 빌드를 Capacitor 등으로 감싸기, 아이콘·스플래시 |
| 서버 저장/치트 방지 | 지금은 기기 저장이 기준. 랭킹 경쟁을 넣으려면 서버 판정 필요 |
| 진짜 PvP 대항전 | 지금은 다른 구단을 흉내 낸 봇 |
| 아트·사운드 | 픽셀 얼굴은 자동 생성, 효과음·음악은 합성음. 전문 아트·BGM으로 교체 권장 |
| 다국어 | 현재 한국어만 |
| 개인정보처리방침, 연령 등급 | 스토어 등록 시 필요 |
| 지표 수집 | D1/D7 리텐션, 첫 세션 길이, 가이드 단계별 이탈 |
| 베타 테스터 피드백 | 손맛, 첫 15분 흐름, 막판 속도 |
