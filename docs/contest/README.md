## 출품 전 확인

- [ ] 소개 페이지 공유 설정을 "링크가 있는 모든 사람"으로 변경
- [ ] 대회 요강의 영상 길이 제한 확인 (보통 1~3분, 현재 67초)
- [ ] 기획서 분량·양식 제한 확인 (지정 양식이 있으면 PDF 내용을 옮겨 적기)
- [ ] 팀/개인 정보, 연락처는 대회 양식에 직접 기입
- [ ] 글꼴 라이선스 표기: Black Han Sans, Jua, Noto Sans KR (SIL Open Font License 1.1). 게임 설정 → "만든 이야기"에도 표기됨

## 검증 결과 (베타 0.13.0)

- 자동 테스트 82개 통과 (`npx vitest run`)
- 휴대폰 CPU 4배 감속 환경에서 60fps, 메모리 약 5MB
- 첫 실행 → 튜토리얼 → 스카우트 → 탭 이동 → 미니게임 → 시즌 종료까지 자동 점검, 콘솔 오류 없음
- 30경기 중계 화면 무작위 재생: 공 위치 이상값 0, 오류 0
- 밸런스 시뮬레이터: 엔딩까지 광고 없이 약 75일, 광고 시청 약 55일, 패스+정회원 약 35일 (하루 1시간)
