# 게임 제작 프롬프트 (러프 버전)

> 아래 블록을 통째로 AI 코딩 에이전트(Claude Code 등)에 붙여 넣어 쓰면 됩니다.
> 참고 게임의 **시스템 구조만** 가져오고, 이름·아트·UI는 전부 새로 만드는 것을 전제로 썼습니다.

---

```
너는 모바일 방치형 게임 개발자야. 아래 기획대로 "조기축구 구단 키우기" 게임의
플레이 가능한 프로토타입을 처음부터 만들어줘.

## 0. 원칙
- 레퍼런스: "선수 뽑기 → 비교 → 영입/판매 → 팀 파워 상승 → 자동 경기" 구조의
  방치형 축구 경영 게임. 구조만 참고하고 이름, 아트, UI, 텍스트는 전부 새로 만든다.
  실존 구단/선수 이름이나 패러디 이름은 쓰지 않는다.
- 테마: 한국 조기축구. 새벽 운동장, 동네 아저씨, 회비, 막걸리 회식 감성.
- 플랫폼: 세로 화면 모바일 웹(나중에 앱으로 감쌀 수 있게).
- 스택: Vite + TypeScript + Phaser 3 (경기 화면) + 가벼운 DOM UI. 저장은 localStorage.
- 아트: 처음엔 도형/이모지 플레이스홀더. 나중에 픽셀 아트로 교체할 수 있게 에셋 경로를 분리.
- 밸런스 수치는 전부 data/*.json 같은 설정 파일로 빼서 코드 수정 없이 조정 가능하게.

## 1. 핵심 루프 (MVP에서 가장 먼저, 가장 잘 만들 것)
1) 스카우트 버튼을 누르면 스카우트권 1개를 쓰고 선수 1명이 나온다.
2) 같은 포지션의 현재 주전과 비교 팝업:
   - 핵심 능력치 2개만 크게, 더 좋으면 초록 ↑, 나쁘면 빨강 ↓
   - ⓘ 누르면 6개 능력치 상세
3) [영입] 주전 교체 / [방출] 현금 받고 판매
4) 팀 파워가 즉시 오르는 연출 (숫자 카운트업)
목표: 버튼 한 번 → 0.5초 판단 → 숫자 상승의 쾌감.

## 2. 선수
- 포지션: GK, LB, CB, RB, CM, CAM, LM, RM, LW, RW, ST
- 포메이션: 4-3-3 기본 (나중에 변경 가능하게)
- 능력치 6개: 스피드, 슈팅, 패스, 드리블, 수비, 체력
- 포지션별 핵심 능력치 2개(비교용)와 3개(카드 요약용) 정의
- 종합 능력치 = 포지션별 가중 평균
- 랜덤 이름(한국식 + 별명 "번개 김씨" 등), 직업(택배기사/치킨집 사장/대학생/전직 선출…), 나이
- 등급 9단계 (= 리그 단계와 이름 공유):
  동네 조기축구 → 구 리그 → 시·도 리그 → K7 → K6 → K5 → K4 → K3 → 국가대표
  등급마다 카드 색과 능력치 범위가 다르다.

## 3. 스카우트 레벨과 확률
- 스카우트 레벨이 오를수록 상위 등급 확률이 오른다. 확률표는 화면에 공개.
- 확률 예시 (설정 파일로):
  Lv10: 1등급 13.5 / 2등급 52 / 3등급 32 / 4등급 2 / 5등급 0.5
  Lv11: 8.95 / 46 / 40 / 4 / 1 / 6등급 0.05  (새 등급이 0.05%로 처음 열리는 순간이 업그레이드 동기)
- 레벨업 비용: 현금, 레벨마다 증가 (예: Lv10→11 = 55,700)
- "다음 레벨 확률 미리보기" UI 필수
- 자동 스카우트: 남길 등급 체크박스(나머지는 자동 판매), 한 번에 쓸 횟수 선택

## 4. 경기
- 팀 파워 = 공격 + 미드 + 수비 (각 라인 선수 능력치 기반)
- 위에서 본 2D 피치에서 22명이 점+이름표로 움직이는 자동 시뮬레이션
- 이벤트 기반: 패스/드리블/슛/선방을 능력치 + 스킬 보정 확률로 굴린다
  (파워 비교 한 번으로 결과를 정하지 말 것)
- 해설 자막 ("김씨 번개 같은 역습!", "골키퍼 아저씨 슈퍼세이브!")
- **진 이유를 보여주기**: 경기 후 요약에 "상대 GK 선방 6회", "후반 체력 저하" 등.
  (레퍼런스 게임의 최대 불만이 "파워가 높은데 진다"였음)
- 경기는 자동으로 이어지고, 그동안 플레이어는 스카우트를 계속 돌린다.

## 5. 리그 / 진행
- 리그당 10팀, 시즌 주차 표시 (Week 1-2 형식)
- 1위 하면 다음 리그로 승격 + 보상
- 상대 팀은 가상의 동네 팀 이름 (○○동 FC, 새벽FC, 막걸리 유나이티드 …)

## 6. 재화 (4~5종으로 줄여서)
- 회비(현금): 경기장 수입, 판매, 경기 보상 → 스카우트 레벨업
- 연락처(스카우트권): 스카우트 1회당 1개
- 젬(프리미엄)
- 작전판(연구 재화): 전술 연구
- 콘텐츠 하나가 재화 하나를 공급하는 구조로 설계

## 7. 방치 수입 (운동장 수익)
- 회비 1/초, 연락처 1/90초가 쌓이고 [수령] 버튼
- 오프라인 누적 상한(예: 8시간) → 하루 여러 번 접속 유도

## 8. 2차 시스템 (MVP 이후)
- 훈련 캠프 (재화 던전): 승부차기 내기 / 동네 풋살 / 운동장 족구
  각각 다른 재화 보상, 난이도 단계, 하루 입장 2회, "최고 단계 소탕" 버튼
- 전술 연구 트리: 노드 업그레이드에 시간 + 작전판, 동시에 1개만 진행
- 팀 스킬: 슬롯 3개, 스킬 뽑기, 효과는 확률 보정 (예: 파워슛 확률 +1%)
- 대회 (비동기 PvP 흉내): 다른 팀 5개 중 골라 도전, 승리 시 별, 기간제 순위,
  매일 새벽 3시 도전권 충전

## 9. 수익화 자리만 만들어두기 (실결제 연동 X, 버튼과 UI만)
- 광고 보상 슬롯 ("벤치에서 쉬기" 테마): 하루 3회 회비/연락처/젬
- 주간 구독 "정회원 회비": 매일 보상 + 스카우트 2배 속도
- 시즌 패스 (무료/프리미엄 트랙)
- 동네 가게 유니폼 스폰서 (치킨집, 철물점, 부동산) = 영구 버프 상품

## 10. 작업 순서
1단계: 데이터 모델(선수/팀/재화/설정 JSON) + 저장/불러오기
2단계: 스카우트 → 비교 → 영입/판매 루프 + 포메이션 화면
3단계: 스카우트 레벨/확률표/자동 스카우트
4단계: 경기 시뮬레이션 + 리그 + 승격
5단계: 방치 수입 + 오프라인 정산
6단계: 훈련 캠프, 연구, 스킬, 대회
7단계: 밸런스 시뮬레이터 스크립트 (무과금 N일 후 팀 파워/리그 예측)

각 단계마다 실행 가능한 상태로 커밋하고, 다음 단계로 넘어가기 전에 나한테 보여줘.
밸런스 수치는 docs/pocket-scout-fc-analysis.md 의 분석을 참고해.
```
