# 새벽 조기축구 비즈니스 모델 (베타 0.11.0)

목표는 두 가지입니다. **매일 다시 들어올 이유**(리텐션)와 **돈을 쓰고 싶은 순간**(수익화)을 만드는 것입니다.
수익 장치는 "무료로도 끝까지 갈 수 있지만, 쓰면 더 빠르고 더 예쁘다"는 원칙을 따릅니다.

## 1. 리텐션 장치

| 장치 | 플레이어가 돌아오는 이유 | 설계 포인트 |
|---|---|---|
| 7일 출석 | 오늘 보상, 7일째 큰 보상, 연속 출석 보너스 | 하루 빠지면 연속이 끊김 → 매일 접속 습관 |
| 운동장 수익 + 오프라인 상한 | "가득 찼어요!" 전에 수령하러 | 상한(8시간 + 증축)이 접속 간격을 만든다 |
| 경기장 증축 (20단계) | 수입이 오르는 것이 눈에 보임 | 남는 회비를 쓸 곳. 공터 → 돔 구장 |
| 선수 훈련 (선수당 10단계) | 아끼는 선수를 키우는 애착 | 선수를 바꾸면 훈련이 사라짐 → "키울까, 바꿀까" 고민 |
| 선수 도감 (15개국 × 9등급) | 빈칸 채우기, 단계 보상 | 스카우트를 계속할 장기 목표. 팀 파워 영구 보너스(최대 +5%) |
| 행운 룰렛 | 매일 무료 1번 + 광고 2번 | 드문 대박 칸(젬 100, 회비 3시간)으로 기대감 |
| 일일 미션 + 완료 상자 | 하루 할 일 목록 | 03:00 초기화 |
| 가이드 퀘스트 25단계 | 다음 목표가 항상 보임 | 엔딩까지 이어지는 한 줄 |
| 대항전, 시즌 패스, 훈련 캠프 | 하루 입장권, 승리 수 진행 | 기존 장치 |

## 2. 수익 장치

| 장치 | 유형 | 노출 시점 | 가격 |
|---|---|---|---|
| 첫 구매 젬 2배 | 첫 결제 전환 | 상점 젬 팩마다 "첫 구매 2배" 배지 | 젬 팩 가격 그대로 |
| 창단 패키지 | 스타터 팩 (72시간, 1회) | 튜토리얼 직후 팝업 | ₩1,200 |
| 승격 기념 패키지 | 감정이 가장 좋은 순간 (24시간) | 승격 축포 직후 | ₩4,900 |
| 돌아온 감독님 패키지 | 복귀 유저 (48시간 이상 미접속, 24시간) | 접속 즉시 | ₩2,500 |
| 오프라인 보상 2배 | 보상형 광고 (하루 1번) | 복귀 화면의 "2배로 받기" | 광고 |
| 행운 스카우트 | 보상형 광고 (하루 3번) | 스카우트 확률 화면 | 광고: 30분 동안 확률 레벨 +2 |
| 정회원 (주간 구독) | 핵심 결제 | 빠른 메뉴, 확률 화면 | ₩6,600/주: 확률 레벨 +5, 운동장 연락처 3배·회비 +30%, 오프라인 +4시간, 매일 📞400 💎30 |
| 시즌 패스 (60단계) | 1회 결제 | 빠른 메뉴 | ₩17,000: 프리미엄 회비 4배, 📞150 / 📯600 / 📋300 |
| 룰렛 추가 회전 | 광고 2번, 그다음 젬 30 | 룰렛 화면 | 광고 / 젬 |
| 구단 꾸미기 | 치장 (전투력과 무관) | 상점, 구단 메뉴 | 유니폼 💎80~300, 엠블럼 변경 💎20 (첫 변경 무료) |
| 기존 | 정회원 구독, 시즌 패스, 일일 특가, 젬 팩, 슈퍼스타 제안, 스폰서, 스킬 슬롯 | | ₩3,300~₩110,000 |

- 한정 특가는 빠른 메뉴의 빨간 🎁 버튼에 남은 시간이 계속 표시됩니다.
- 프로토타입이라 결제는 확인 창 후 바로 지급(가짜)이고, 광고는 1.5초 대기입니다.

## 3. 밸런스 (시뮬레이터 `npm run sim`, 하루 4번 × 15분 = 하루 약 1시간)

시드 16개의 가운데 값입니다. 플레이 시간은 일수와 거의 같습니다(하루 1시간).

| 플레이어 | 엔딩까지 | 결제 |
|---|---|---|
| 무과금, 광고 안 봄 | **약 65일** (42~84일) | ₩0 |
| 무과금, 광고 봄 | **약 52일** (37~63일) | ₩0 |
| 광고 + 시즌 패스 + 정회원 | **약 35일** (20~46일) | 약 ₩5~6만 (정회원 5~7주 + 패스) |

설계 의도:
- **단계마다 약 2주씩 차이**를 둬서 광고 시청과 결제가 확실히 체감되게 했습니다.
- **결제 가치의 핵심은 "더 좋은 선수가 나오는 확률"입니다.** 단순히 연락처 개수를 늘리는 것보다 체감이 큽니다.
- 높은 리그 AI는 리그 단계마다 팀 파워 +5.5%입니다. 같은 리그에서 승격에 실패할 때마다 이 보너스가 0.25%p씩 줄어서 영영 막히는 벽은 없습니다.
- 회비와 연락처 수급:
  - 운동장 연락처 1개/300초
  - 광고 연락처 100 × 3번
  - 젬 100개 → 연락처 300개
