# 새벽 조기축구

새벽 동네 운동장에서 시작해 **세계 정상(슈퍼스타 리그 우승)**까지 가는 방치형 축구 구단 게임입니다. 현재 **베타 0.9.0**.
레퍼런스 게임(Pocket Scout FC)의 시스템 구조만 참고했고, 이름·그림·문구는 전부 새로 만들었습니다.
분석 문서는 [`docs/pocket-scout-fc-analysis.md`](docs/pocket-scout-fc-analysis.md), 제작 프롬프트는 [`docs/rebuild-prompt.md`](docs/rebuild-prompt.md)에 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (휴대폰 세로 화면 기준)
npm test           # 게임 규칙 단위 테스트
npm run sim        # 밸런스 시뮬레이터 (무과금, 하루 4번 × 15분 접속)
npm run sim -- 60 2 10   # 60일, 하루 2번, 10분씩
npm run build:artifact   # 단일 HTML(dist-artifact/index.html)로 빌드
```

## 게임 구조

| 시스템 | 내용 |
|---|---|
| 스카우트 | 연락처 1개로 선수 1명. 현재 주전과 핵심 능력치 2개를 비교해 영입/방출 |
| 선수 등급 = 리그 단계 | 동네 조기축구 → 지역 리그 → 3부 → 2부 → 세미프로 → 프로 1부 → 엘리트 → 월드클래스 → 슈퍼스타 |
| 세계 무대 | 15개국 선수(국기·국가별 이름), 리그별 경기장과 관중, 세미프로부터 해외 클럽 |
| 선수 특성 | 프리킥 장인, 거미손, 신사 등 10종. 높은 등급일수록 자주 붙음 |
| 스카우트 레벨 | 회비로 올림. 확률표 공개 + 다음 레벨 미리보기 |
| 자동 스카우트 | 남길 등급 체크, 업그레이드면 멈추고 비교, 아니면 자동 방출 |
| 경기 | 패스·찬스·슛·선방·반칙·프리킥·페널티킥·카드를 확률로 굴리는 2D 자동 시뮬레이션, 해설 자막, **진 이유 표시** |
| 경기 운영 | 닥공 / 균형 / 버스 세우기 |
| 미션·가이드 | 일일 미션 5종 + 완료 상자, 엔딩까지 23단계 가이드 퀘스트 |
| 리그 | 10팀 홈·원정 18경기, 1위 승격. 슈퍼스타 리그 우승이 엔딩 |
| 운동장 수익 | 회비/연락처가 계속 쌓임 (오프라인 최대 8시간) |
| 훈련 캠프 | 승부차기 내기(미니게임, 호루라기) / 동네 풋살(연락처+회비) / 운동장 족구(작전판), 소탕 |
| 전술 연구 | 코칭·스카우팅·구단 운영 트리. 작전판 + 시간, 한 번에 하나 |
| 팀 스킬 | 호루라기로 소환, 3슬롯(+1 유료), 중복으로 레벨업 |
| 동네 대항전 | 다른 구단 5팀 중 골라 도전, 별 순위, 매일 03:00 초기화 |
| 상점 | 벤치 휴식(광고), 오늘의 슈퍼스타, 정회원 구독, 시즌 패스, 일일 특가, 젬, 동네 스폰서 — **결제는 가짜**(확인 후 바로 지급) |
| 저장 | 브라우저 + claude.ai 계정 저장, 저장 코드 내보내기/가져오기, 이전 버전 자동 이전 |

## 코드 구조

```
src/data/      밸런스 수치와 콘텐츠 (balance, research, skills, training, shop, teams)
src/game/      게임 규칙. DOM을 모르는 순수 로직이라 테스트·시뮬레이터에서 그대로 쓴다
  game.ts      모든 동작 (스카우트, 경기, 리그, 연구, 스킬, 캠프, 대회, 상점)
  match.ts     경기 엔진과 결과 이유 설명
  league.ts    일정, 순위, AI 팀
  state.ts     저장 데이터 형식, 하루 초기화(03:00)
src/ui/        화면 (탭별 screens/, 공용 모달 shared.ts, 경기장 캔버스 pitch.ts, 픽셀 얼굴 avatar.ts)
src/storage.ts 저장: 브라우저 localStorage + claude.ai 아티팩트에서는 보는 사람 전용 db 문서
scripts/       밸런스 시뮬레이터, 아티팩트 빌드
tests/         vitest 단위 테스트
```

## 밸런스

수치는 전부 `src/data/*.ts`에 있습니다. 회비 보상은 대부분 "운동장 몇 초치 × 리그 배율(`incomeMult`)"로 정해서, 한 곳을 바꾸면 전체가 같이 움직입니다.
현재 기준 무과금으로 엔딩까지 시뮬레이터에서 **약 21~34일**(하루 4번 × 15분), 하루 2번 × 10분도 약 32~33일이 걸립니다.

베타 출시 전 점검 목록은 [`docs/beta-checklist.md`](docs/beta-checklist.md)에 있습니다.
